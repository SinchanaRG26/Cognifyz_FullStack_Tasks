### ✨ Features

#### 🔌 **RESTful API Endpoints**
- ✅ GET all products - `/api/products`
- ✅ GET single product by ID - `/api/products/:id`
- ✅ POST create new product - `/api/products`
- ✅ PUT update existing product - `/api/products/:id`
- ✅ DELETE product - `/api/products/:id`
- ✅ Search products - `/api/search/:query`
- ✅ Get statistics - `/api/stats`

- ✅ **Home Page** with tabbed interface for all CRUD operations
- ✅ **Products Page** with grid view of all products
- ✅ **Real-time Statistics** showing total products, value, stock, categories
- ✅ **Add Product** form with validation
- ✅ **Update Product** functionality
- ✅ **Delete Product** with confirmation

**🔍 API Endpoints Documentation**
_Method	Endpoint	Description	Request Body	Response_
- GET	/api/products	Get all products	None	Array of products
- GET	/api/products/:id	Get single product	None	Single product object
- POST	/api/products	Create new product	{ name, price, category, inStock }	Created product
- PUT	/api/products/:id	Update product	{ name, price, category, inStock }	Updated product
- DELETE	/api/products/:id	Delete product	None	Success message
- GET	/api/search/:query	Search products	None	Matching products
- GET	/api/stats	Get statistics	None	Product stats
  
**🎯 How to Use**
_**Home Page**__

3. View Products - See all products with edit/delete options

5. Update Product - Modify existing products
6. Delete Product - Remove products
7. Search - Find products by name or category
8. All operations show toast notifications

2. See all products in grid layout
3. Edit or delete directly from this page
