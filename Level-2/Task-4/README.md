### ✨ Features

#### 📝 **Registration Form**
- ✅ Real-time password strength meter with live checklist
- ✅ Username availability check with debounce
- ✅ Email format validation
- ✅ Age validation (18-100 years)
- ✅ Phone number validation with character counter
- ✅ Confirm password matching
- ✅ Terms & Conditions checkbox
- ✅ Live user counter

#### 👤 **Profile Page**
- ✅ Dynamic profile display showing most recent user
- ✅ Edit profile functionality with inline form
- ✅ Settings panel with working toggles
- ✅ Dark mode toggle
- ✅ Language selector (English, Hindi, Kannada, Telugu)
- ✅ Notification preferences
- ✅ Recent activity timeline
- ✅ User statistics

#### 📊 **Dashboard Page**
- ✅ Real-time user list
- ✅ Search functionality to filter users
- ✅ Statistics cards (total users, latest user, last updated)
- ✅ Auto-refresh after new registrations
- ✅ Empty state handling

#### 🔄 **Client-Side Routing**
- ✅ Smooth navigation between pages
- ✅ URL hash updates (#home, #profile, #dashboard)
- ✅ Browser back/forward button support
- ✅ Loading states for better UX
- ✅ No page reloads

#### 🎨 **UI/UX**
- ✅ Professional gradient designs
- ✅ Smooth animations and transitions
- ✅ Toast notifications for all actions
- ✅ Fully responsive design
- ✅ Interactive hover effects

****🔍 Validation Rules:**
- Field	Validation Rules
- Username	Min 3 characters, must be unique
- Email	Valid email format (e.g., name@domain.com)
- Password	Min 8 chars, 1 uppercase, 1 number, 1 special char
- Confirm Password	Must exactly match password
- Age	Between 18 and 100 years
- Phone	Exactly 10 digits

🎯 How to Use:

_**Home Page:**_
1. Fill in all registration fields
2. Watch real-time validation as you type
3. Password strength meter updates dynamically
4. Check username availability
5. Accept terms to enable submit button
6. Click Register to save user

_**Profile Page**_
1. View most recent user's profile
2. Click Edit Profile to modify details
3. Make changes and click Save Changes
4. Click Settings to customize preferences
5. Try dark mode toggle
6. Change language from dropdown
7. All actions show toast notifications

**Dashboard Page**__
1. View all registered users
2. Use search bar to filter users
3. Stats update automatically
4. New users appear after registration
